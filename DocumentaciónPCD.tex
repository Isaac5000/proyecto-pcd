\section{Ejercicio 1: ReentrantLock}
    Supongamos dos hilos con la siguiente funcionalidad en un \textbf{centro de alto rendimiento}: 
    \begin{itemize}
        \item Un primer hilo genera una matriz \textbf{A} (3x3) con enteros que representa métricas de 
        entrenamiento (por ejemplo: fuerza, velocidad y resistencia en 3 días), calcula el 
        “impacto acumulado” \textbf{A² = A·A} e imprime: \\
        \\
        \textcolor{black!70}{
        A x A \\
        a1 a2 a3 \\
        a4 a5 a6 \\
        a7 a8 a9 \\
        \\
        x   \\
        \\
        a1 a2 a3 \\
        a4 a5 a6 \\
        a7 a8 a9 \\
        \\
        A2 \\
        \\
        r1 r2 r3 \\ 
        r4 r5 r6 \\
        r7 r8 r9 \\
        }
        \item El otro hilo hace lo mismo, pero calcula \textbf{A + A} (doble carga) e imprime: \\
        \\
        \textcolor{black!70}{
        A + A \\
        \\
        ...\\ 
        2A \\
        ...\\
        }
    \end{itemize} 
    Cada hilo repite su actividad \textbf{10 veces}. Desarrollar un programa concurrente en Java. La 
    sincronización necesaria se resolverá usando cerrojos \textcolor{black!70}{ReentrantLock}.

    \subsection{Cuestiones planteadas en los ejercicios}
        \begin{enumerate}[label=\alph*)]
        \item \textbf{Si no usas sincronización, ¿cómo podría ser la salida por pantalla?}

        Como regla general, si no usas sincronización, la salida por pantalla es caótica e impredecible. En este caso, dado que ambos 
        hilos (SumaMatriz y CuadradoMatriz) están accediendo a la pantalla para imprimir sus resultados, sin sincronización podrían 
        intercalarse las impresiones de ambos hilos. Esto podría resultar en una salida mezclada donde partes de la matriz de SumaMatriz 
        se imprimen junto con partes de la matriz de CuadradoMatriz, haciendo que sea difícil o imposible entender los resultados.

        \noindent En el caso particular de java cada System.out.println() es una operación atómica, lo que significa que cada llamada a esta 
        función se ejecutará completamente sin ser interrumpida por otro hilo. Sin embargo, esto no garantiza que las impresiones de ambos hilos 
        no se mezclen, ya que cada hilo podría imprimir varias líneas de la matriz antes de que el otro hilo tenga la oportunidad de imprimir. 
        Por lo tanto, aunque cada línea individual se imprima de manera atómica, la secuencia completa de impresiones podría resultar en una salida 
        caótica si no se sincroniza adecuadamente.
        \end{enumerate}

            package ejercicio1;

            import java.util.Random;
            import java.util.concurrent.locks.ReentrantLock;

            public class Main {
                public static final int NUM_OPERACIONES = 10;
                public static final int LONGITUD_FILAS_Y_COLUMNAS = 3;
                public static final int NUM_0_9 = 10;

                /* Este cerrojo se encarga de bloquear la sección crítica de la pantalla para que no acceda
                * más de un hilo a la vez */ 
                public static ReentrantLock cerrojoPantalla = new ReentrantLock();
                
                /**
                * Función que le da valores aleatorios entre 0 y 9 a una matriz de 3x3,
                * @param matriz Es la matriz que se rellenara con núevos valores aleatorios
                */
                public static void generarMatriz(int[][] matriz){
                    for(int i = 0; i < LONGITUD_FILAS_Y_COLUMNAS; i++) {
                        for(int j = 0; j < LONGITUD_FILAS_Y_COLUMNAS; j++) {
                            Random random = new Random();
                            matriz[i][j] = random.nextInt(NUM_0_9);
                        }
                    }
                }
                
                
                /**
                * Función principal del programa donde se ejecutan dos hilos, uno que se encarga de 
                * hacer el cuadrado de una matriz y otro el doble de una matriz.
                * @param args
                */
                public static void main(String[] args) {
                    CuadradoMatriz cuadrado = new CuadradoMatriz();
                    SumaMatriz suma = new SumaMatriz();
                    cuadrado.start();
                    suma.start();
                    
                    try {
                        cuadrado.join();
                        suma.join();
                    } catch (InterruptedException e) {
                        e.printStackTrace();
                    }
                }
            }

            package ejercicio1;

            public class SumaMatriz extends Thread{
                
                
                @Override
                public void run() {
                    
                    int metricasDeEntrenamiento[][] = 
                        new int[Main.LONGITUD_FILAS_Y_COLUMNAS][Main.LONGITUD_FILAS_Y_COLUMNAS];
                    int impactoAcumulado[][] = 
                        new int[Main.LONGITUD_FILAS_Y_COLUMNAS][Main.LONGITUD_FILAS_Y_COLUMNAS];
                    
                    for (int operacionesRealizadas = 0; 
                        operacionesRealizadas < Main.NUM_OPERACIONES; operacionesRealizadas++) {
                        
                        Main.generarMatriz(metricasDeEntrenamiento);
                        
                        // Suma de la matriz A + A (2A)
                        for (int i = 0; i < Main.LONGITUD_FILAS_Y_COLUMNAS; i++) {
                            for (int j = 0; j < Main.LONGITUD_FILAS_Y_COLUMNAS; j++) {
                                impactoAcumulado[i][j] = 
                                    metricasDeEntrenamiento[i][j] + metricasDeEntrenamiento[i][j];
                            }
                        }
                        
                        
                        /* Aquí se bloquea el cerrojo de la pantalla para asegurar que este recurso no
                        * compartible no sea usado por más de un proceso a la vez
                        */
                        Main.cerrojoPantalla.lock();
                        
                        System.out.println("A + A\n");
                        
                        for (int[] fila : metricasDeEntrenamiento) {
                            for (int valor : fila) {
                                System.out.print(valor + "a ");
                            }
                            System.out.println();
                        }
                        System.out.println("\n+\n");

                        for (int[] fila : metricasDeEntrenamiento) {
                            for (int valor : fila) {
                                System.out.print(valor + "a ");
                            }
                            System.out.println();
                        }
                        
                        System.out.println("\n2A\n");
                        
                        for (int[] fila : impactoAcumulado) {
                            for (int valor : fila) {
                                System.out.print(valor + "r ");
                            }
                            System.out.println();
                        }
                        System.out.println();
                        
                        Main.cerrojoPantalla.unlock();
                        
                    }
                    
                }
            }

        \begin{lstlisting}[language=Java, title={Clase CuadradoMatriz}]
            package ejercicio1;

            public class CuadradoMatriz extends Thread {

                @Override
                public void run() {

                    int metricasDeEntrenamiento[][] = 
                        new int[Main.LONGITUD_FILAS_Y_COLUMNAS][Main.LONGITUD_FILAS_Y_COLUMNAS];
                    int impactoAcumulado[][] = 
                        new int[Main.LONGITUD_FILAS_Y_COLUMNAS][Main.LONGITUD_FILAS_Y_COLUMNAS];

                    for (int operacionesRealizadas = 0; 
                        operacionesRealizadas < Main.NUM_OPERACIONES; operacionesRealizadas++) {

                        Main.generarMatriz(metricasDeEntrenamiento);

                        // Cálculo del cuadrado de la matriz
                        for (int i = 0; i < Main.LONGITUD_FILAS_Y_COLUMNAS; i++) {
                            for (int j = 0; j < Main.LONGITUD_FILAS_Y_COLUMNAS; j++) {
                                impactoAcumulado[i][j] = 0;
                                for (int k = 0; k < Main.LONGITUD_FILAS_Y_COLUMNAS; k++) {
                                    impactoAcumulado[i][j] += 
                                        metricasDeEntrenamiento[i][k] * metricasDeEntrenamiento[k][j];
                                }
                            }
                        }


                        /*
                        * Aquí se bloquea el cerrojo de la pantalla para asegurar que este recurso no
                        * compartible no sea usado por más de un proceso a la vez
                        */
                        Main.cerrojoPantalla.lock();
                        
                        System.out.println("A x A\n");
                        
                        for (int[] fila : metricasDeEntrenamiento) {
                            for (int valor : fila) {
                                System.out.print(valor + "a ");
                            }
                            System.out.println();
                        }
                        System.out.println("\nx\n");

                        for (int[] fila : metricasDeEntrenamiento) {
                            for (int valor : fila) {
                                System.out.print(valor + "a ");
                            }
                            System.out.println();
                        }
                        
                        System.out.println("\nA2\n");
                        
                        for (int[] fila : impactoAcumulado) {
                            for (int valor : fila) {
                                System.out.print(valor + "r ");
                            }
                            System.out.println();
                        }
                        System.out.println();

                        Main.cerrojoPantalla.unlock();

                    }

                }
            }

    pruebas físicas. En el sistema se dispone de \textbf{3 instancias} de la clase Panel proporcionada en

    Cada hilo repite \textbf{3 veces} la siguiente secuencia:
    \begin{enumerate}[label=\arabic*)]
        \item Cada hilo genera aleatoriamente una \textbf{matriz 5x5} de enteros para cada \textbf{uno de los 4

        intentos} para conseguir la mejor marca en cada ejercicio. 
        \item Para cada deportista, se calcula su \textbf{mejor marca por ejercicio}, seleccionando 
        el \textbf{máximo} (o mínimo, en caso de ser tiempo) de los 5 intentos de cada fila. El 
        resultado para cada deportista es un \textbf{vector de 5 elementos} (uno por ejercicio). 
        \item A partir de los resultados anteriores, se construye una \textbf{matriz resumen de 
        4x5 llamada R}, que representa el resumen del equipo: 
        \begin{itemize}
            \item Columna 1: mejor marca de cada deportista para el ejercicio 1 
            \item Columna 2: mejor marca de cada deportista para el ejercicio 2
            \item Columna 3: mejor marca de cada deportista para el ejercicio 3 
            \item Columna 4: mejor marca de cada deportista para el ejercicio 4 
            \item Columna 5: mejor marca de cada deportista para el ejercicio 5
        \end{itemize}
        \item Muestra en \textbf{un panel que esté disponible} la siguiente salida: \\
        \\
        \textcolor{black!70}{
        Usando panel P el hilo (equipo) id \\
        \\
        Matriz R (resumen del equipo X: mejores marcas) = ... \\
        \\
        Terminando de usar panel P el hilo (equipo) id \\
        \\ }
        Los pasos 1, 2, 3 y 4 se repiten \textbf{3 veces} por equipo. \\
        \\
        Los 10 hilos (equipos) comparten los \textbf{3 paneles} del sistema y, usando \textbf{semáforos}, se debe 
        añadir la sincronización necesaria para que: 
        \begin{itemize}
            \item nunca dos hilos escriban simultáneamente en el mismo panel, 
            \item el uso de los paneles sea eficiente (máximo paralelismo posible). 
        \end{itemize}
        La sincronización hay que resolverla \textbf{con semáforos}.
    \end{enumerate}

\section{Ejercicio 3: Monitores}
    En este ejercicio se quiere simular mediante un programa concurrente la actividad en 
    un \textbf{gimnasio}. El flujo para entrenar es el siguiente: 
    \begin{enumerate}
        \item \textbf{Acceso al gimnasio mediante tornos}): Un cliente llega al gimnasio y debe pasar 
        por \textbf{uno de los 3 tornos de acceso} para validar su entrada. Cada torno tiene su \textbf{cola 
        individual}. El tiempo que tarda el cliente en completar el acceso (validación + entrada) 
        es \textbf{X milisegundos} (valor aleatorio entre 1 y 5). Nota: el cliente debe situarse en 
        el \textbf{primer torno} que encuentre libre; si los 3 están ocupados, esperará en la \textbf{cola del 
        torno} que tenga menor tiempo de espera. 
        \item \textbf{Elección de zona de entrenamiento}: Tras pasar la zona de tornos, el cliente elige a 
        qué \textbf{zona de entrenamiento} dirigirse en función del tiempo estimado de espera. El 
        gimnasio tiene \textbf{4 zonas}, y \textbf{cada zona dispone de 5 máquinas: Zona 1 – Cardio, Zona 
        2 – Fuerza, Zona 3 – Funcional, Zona 4 - Estiramientos} . Un cliente \textbf{puede entrar} a 
        una zona si al menos una de sus máquinas está libre. Si hay varias zonas con máquinas 
        libres elegirá una de forma aleatoria. Si \textbf{las 5 máquinas} de una zona están ocupadas, el 
        cliente debe esperar en la \textbf{cola de acceso de esa zona} (una cola por zona). 
        \item Dentro de la \textbf{zona de Cardio} existe una \textbf{bicicleta premium} que tiene una \textbf{cola 
        exclusiva propia}, independiente de la cola general de la zona. Un cliente puede entrar 
        en Cardio si hay alguna de las 5 máquinas libres (según el paso 2). Si el cliente desea 
        usar la \textbf{bicicleta premium} (decisión con probabilidad del 30%) y está ocupada, deberá

    \section{Ejercicio 4: Paso de Mensajes Asíncrono}
    Consideremos un conjunto de 50 aficionados que llegan a un estadio de fútbol para entrar a un 
    partido y deben pasar por el control de acceso tras validar su entrada. Para acceder hay dos 
    tornos con sus respectivas colas: la cola R y la cola L, siendo la cola R más rápida que la L (por 
    ejemplo, porque el torno R tiene lector más eficiente o un agente adicional). Cada aficionado 
    tiene que usar una cola para validar su entrada durante un tiempo estimado (valor aleatorio 
    entre 1 y 10). El controlador de accesos, cuando llega un nuevo aficionado a validar la entrada, 
    estima su tiempo de validación y a aquellos aficionados cuyo tiempo estimado sea menor o 
    igual a 5, se les asignará el torno más rápido, es decir, la cola R, a los demás aficionados se les 
    asignará el torno L. Durante el partido, cada aficionado puede salir de su grada para ir a los 
    baños o a la zona de compra de comida y bebida. Para volver a su zona, debe pasar de nuevo 
    por los tornos, repitiendo el proceso de validación. Este ciclo de “salir y volver a entrar” lo 
    realizará 5 veces a lo largo del partido. Es decir, cada hilo repite 5 veces la siguiente secuencia 
    de acciones: \\
    \\
    \begin{enumerate}
        
    \item Realiza una acción previa (usando Sleep ()), por ejemplo caminar hacia los baños. 
    \item Solicita ponerse en una cola (R o L según el controlador de accesos le indique). 
    \item Realiza la validación en el torno asignado. 
    \item Libera la cola (deja libre el torno), 
    \item Imprime en pantalla la información que se indica a continuación:\\
    \\
    \textcolor{black!70}{
    \hspace*{2em}“Aficionado id ha usado la cola X \\
    \\
    \hspace*{2em}Tiempo de validación = T \\
    \\
    \hspace*{2em}Thread.sleep(T) \\
    \\
    \hspace*{2em}Aficionado id liberando la cola X” \\
    \\
    }
    donde X es la cola asignada y T el tiempo de validación. 
    \end{enumerate}
    Desarrollar un programa concurrente en Java para resolver el problema anterior usando como 
    mecanismo para la sincronización el paso de mensajes asíncrono.
